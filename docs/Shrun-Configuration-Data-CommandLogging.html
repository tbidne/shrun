data CommandLoggingP (p :: ConfigPhase) Source #

Holds config related to (console and file) command logging.

Constructors

MkCommandLoggingP 

Fields

  • bufferLength :: ConfigPhaseF p BufferLength

    Max log length held by the buffer for the ReadBlockLineBuffer ReadStrategy.

  • bufferTimeout :: ConfigPhaseF p BufferTimeout

    Max time the buffer will hold a log before flushing it, for the ReadBlockLineBuffer ReadStrategy.

  • pollInterval :: ConfigPhaseF p PollInterval

    How often to poll commands for logs, in microseconds.

  • readSize :: ConfigPhaseF p ReadSize

    Determines the max log size we read from commands in one go. Note this is not on commandLogging or fileLogging since it affects both.

  • readStrategy :: ConfigPhaseF p ReadStrategy

    Reading strategy.

  • reportReadErrors :: SwitchF p ReportReadErrorsSwitch

    Determines if we should log read errors.
