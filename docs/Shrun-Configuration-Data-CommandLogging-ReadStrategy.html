data ReadStrategy Source #

Different read strategies for simplicity vs. potential prettier formatting.

Constructors

ReadBlock

Reads N bytes at a time.

ReadBlockLineBuffer

Reads N bytes at a time, but attempts to distinguish "complete" (newline terminated) vs. "partial" (anything else) reads. We do this to make the file log output prettier.
