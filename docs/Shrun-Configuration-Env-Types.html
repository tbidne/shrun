    Functions to clean up running commands.

  • commands :: NESeq CommandP1

    Holds notification environment. | Commands

  • commandGraph :: CommandGraph

    Command graph.

  • commandStatusMap :: TCommandStatusMap

    Map from CommandIndex to Command and its status. Used for determining e.g. which commands have completed failed not run.

    The statuses are TVars since they are mutable, though the map itself can be pure since its structure is fixed at initialization. In fact, we could probably swap TVar for IORef since we only update the status from a single thread (each command has its own thread).
